## Deployment audit follow-up

The live audit found that normal Coolify parsing adds its shared application network to PostgreSQL and injects all runtime values into every service. Source-only Compose validation did not catch this transformation. The GitHub manual workflow passed end to end at cf0fafa (run 43348152627), including exact public SHA verification. The host audit then reproduced the platform network transformation. The deployment is moving to raw Compose mode with fixed project/ownership labels, existing external volume names and live network/environment verification. No data volumes are being deleted or replaced. The scoped Coolify API hides the custom start command, so CI relies on required raw mode plus the fixed project name in source; the host audit checks the resulting project/network/credential boundaries. Four deployment regressions cover scoped responses, required raw mode, superseded main commits and failed deployment receipts; all four pass locally and are included in CI. A subsequent CI run exposed a brief enabled-button contrast failure during its disabled-opacity transition. Buttons now animate only shadow/transform so text and opacity reach their accessible state immediately; the existing axe assertion remains unchanged. All credential variables were verified runtime-only using the actual is_buildtime API field; the old image configuration/history scan found none of the generated credential values.

The raw-mode CI validation passed (including the contrast fix), but Coolify's legacy raw label handler rejected mapping labels before touching the running app. Labels now use its required list form, with an explicit compatibility guard. The candidate passed an in-memory preflight through the installed Coolify raw parser: actual Docker Compose parsing preserved service networks, environment scopes, exact external volumes and migration prerequisites. The existing application model was not saved or changed by that preflight.

A later GitHub run caught the document-title accessibility check racing Next's streamed navigation metadata. Browser accessibility scans now explicitly wait for the configured Sibol title before evaluating all existing axe rules. Server UDP DNS is also failing while TCP DNS/TLS succeeds; host connectivity is being checked before rollout.
