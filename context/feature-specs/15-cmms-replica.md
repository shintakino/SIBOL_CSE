# CMMS replica for CSE — current product scope

User-directed replacement, 19 November 2026. This specification supersedes the earlier learner feature scope and the first CMMS-inspired redesign. The user requested an exact replica of the neighboring `../CMMS-REVIEWER` interface, adapted for CSE, and removal of Sibol's extra features.

## Experience

Match the reference's system typography, slate/white/green palette, sticky brand/status/account header, personalized encouragement banner, horizontal pill tabs, icon statistics, bordered gradient launcher cards, domain grid, quiz frame, explanation panel, question palette, score card and recent-history rows. Retain responsive layouts, accessible controls, optional dark mode and reduced motion. The reference’s emoji indicators intentionally replace the earlier Lucide-only learner presentation. Use the existing shadcn foundation for buttons/dialogs; do not copy the reference's unsafe HTML rendering or authentication.

The six tabs are Dashboard, Mock Simulation, Topic Drills, Flashcards, Study Cheatsheet, and Analytics & History. Dashboard provides exams taken, actual average score, missed-question count, bookmark count, Daily Randomized Challenge (25), Full Practice Mock (50), Quick 10 Sprint and Weakness Radar Drill. Mock presets contain 25/50/75 unique questions with server-owned profile-proportional durations. They are practice simulations, not official full CSE forms. Topic cards drill the selected category/subcategory with at most 50 available questions. Missed and bookmarked sets use only the signed-in learner's eligible questions, with explicit empty states and no unrelated fallback.

Flashcards and the cheatsheet contain original CSE concepts/formulas rather than marketing content or bulk question keys. Analytics shows actual completed attempts, scores and history. Banner percentages reflect recorded practice performance, never invented readiness/pass probability. Daily streaks derive from actual completed daily challenges in the learner's timezone. Practice choice answers reveal feedback immediately after acknowledged server save/commit; ordering uses an explicit check. Strict mocks withhold feedback until finalization. Support existing question figures, image choices, keyboard ordering, bookmarks, flags, elimination, save recovery, refresh, exit/resume and results. Any printable achievement must identify itself as an independent practice summary, never an official CSC certificate.

## Removed learner features

Remove weekly planning, diagnostic onboarding/assessments, lesson library/progress, spaced-review scheduling UI, dedication/preferences panels, private-note editing, full-text search, advanced first-exposure/readiness analytics, configurable mock blueprints and design-preview screens from the learner app. Replace old public learner routes with redirects to their corresponding replica tabs or 404 for retired tools. Account controls are compact: track, appearance, export/deletion and sign-out. Keep invitation-only accounts and role-protected editorial/invitation operations separate from the six learner tabs.

Existing accounts, published content, assets, attempts, answers, notes and database tables are preserved. Backend compatibility services may remain for historical records/operator tooling; they do not expose retired learner screens. No destructive data migration, reference database access, credential copying, third-party question publication or marketing bank import is authorized by this UI replacement.

## Technical invariants and verification

Keep Next.js, Hono/oRPC, Bun, Better Auth, PostgreSQL/Drizzle and Docker/CI. Reuse owner locks, pinned versions/choice order, revision checks, idempotent creation and single-result finalization. Do not ship answer keys in initial quiz DTOs or circumvent strict assessment locks through alternate endpoints. Server-side catalog validation excludes held/unpublished/blocked/wrong-track content. Add focused tests for new 25/50/75 lengths, missed/bookmark selection, daily streak accounting, ownership, retry and feedback restrictions. Update browser flows to the reduced product scope and compare actual screenshots against the local reference on mobile and desktop. Never label archived-feature UI checks as current acceptance.

Legacy lesson-inventory and two-full-form acceptance requirements apply only if the retired lesson/official full-form experience is restored. The replica’s 25/50/75-question practice simulations do not claim official full-paper coverage. Current acceptance still requires licensed/reviewed eligible questions, reviewed image descriptions, private ownership, scoring/deadline/retry integrity, account recovery, backups and mobile/accessibility checks. Existing held questions remain held.
